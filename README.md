# 💼 Frontend Dashboard para Facturación

Panel moderno en **React + TypeScript + Tailwind + Axios** para consumir una API de facturación desarrollada en .NET.

## 🚀 Tecnologías

- React
- TypeScript
- Vite
- Axios
- Tailwind CSS
- JWT
- Recharts
- Lucide Icons

## ⚙️ Requisitos

Debes tener corriendo la API backend en:

```txt
http://localhost:5000
```

## 🔧 Configuración

Crea un archivo `.env` basado en `.env.example`:

```env
VITE_API_URL=http://localhost:5000/api
```

## ▶️ Ejecutar

```bash
npm install
npm run dev
```

Abrir:

```txt
http://localhost:5173
```
